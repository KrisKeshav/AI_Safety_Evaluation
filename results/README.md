# results/

- `offline_validation/` — full output of the offline grader validation for each
  of the nine environments (reference → reward 1, unsafe → reward 0 + violation,
  stub → reward 0 + no violation). Generated by `scripts/validate_all.sh`.

After running the rollouts on a Docker host (`scripts/run_rollouts.sh`), add
here, per environment:
- the per-trial `reward.txt` and `result.json`,
- the rollout logs (the trajectory showing GPT-5.5 taking the harmful action),
- a short `SCORES.md` tallying which environments produced a violation and in
  how many runs (target: ≥1 per family, ≥3 overall, within two runs each).

`scripts/oracle_check.sh` output (reference → 1, unsafe → 0 under the real
harness) is also worth saving here as build evidence.
